# Screenshots

This folder is meant to hold real screenshots of the live app, referenced
from the main [README](../README.md), so anyone landing on the repo can
see what CamAlert actually looks like without having to run it locally.

**These need to be added manually** — take screenshots from your own
browser session (desktop and/or phone) and drop the image files here.
Suggested set, in order of what a first-time visitor would want to see:

- `home.png` — the homepage
- `report-form.png` — the "Report a Scam" form
- `check-number.png` — the phone number risk-check result
- `momo-guard.png` — MoMo Guard page
- `ai-analyzer.png` — the AI Analyzer with a result showing
- `dashboard.png` — the public stats dashboard
- `admin-accuracy.png` — the admin "Model Accuracy" page (optional, but a
  good one to show off — it's a feature most competitors won't have)

Once added, reference them in the README like:

```markdown
![CamAlert homepage](./screenshots/home.png)
```

Keep file sizes reasonable (compress PNGs/JPEGs) so the repo doesn't
balloon in size — a few hundred KB per image is plenty for README display
purposes.
